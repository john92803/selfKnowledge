這個目錄收錄訓練與評估機器學習模型時，如何讓結果可信、可重現、可比較的做法。程式碼層級的 Python 工程（相依套件、測試、格式化）不放這裡。

| 條目 | 摘要 | 狀態 | 優先度 |
|---|---|---|---|
| [實驗可重現性](reproducibility/) | 固定隨機來源，讓同一份程式與設定跑出相同結果。 | 待學習 | 高 |
| [資料切分與資料洩漏](data-leakage-and-splitting/) | 切分訓練與測試資料時，避免同一來源的樣本落在兩邊而高估模型表現。 | 待學習 | 高 |
| [引用第三方程式碼的方式](third-party-code/) | 在自己的專案中使用並修改別人的程式碼時，保持來源可追溯、可更新。 | 待學習 | 中 |
| [混合精度訓練](mixed-precision/) | 讓部分運算使用半精度浮點數，以加快訓練並減少記憶體用量。 | 待學習 | 中 |
| [實驗設定管理](experiment-config/) | 用設定檔切換實驗，而不是複製整份訓練程式。 | 待學習 | 中 |
| [實驗追蹤](experiment-tracking/) | 有系統地記錄每次訓練的設定、指標與產出，方便比較不同實驗。 | 待學習 | 中 |
