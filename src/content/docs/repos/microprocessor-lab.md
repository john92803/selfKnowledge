## 技術棧

- **平台**：8051 微控制器
- **語言**：A51 組合語言（lab4–lab6）、Keil C51（lab7–lab11）
- **工具鏈**：Keil，使用其提供的 `reg51.h` 與 `intrins.h`
- **硬體介面**：指撥開關、LED、七段顯示器、4×4 矩陣鍵盤、外部中斷 `INT0` 與 `INT1`

## 觀察

做得好的地方：

- 涵蓋範圍由淺入深：從暫存器層級的多位元組運算與間接定址，到 C 語言的周邊控制與中斷。
- 鍵盤掃描抽成共用的 `kb44.h`，包含消除彈跳與等待放開的處理，避免重複觸發。
- README 以表格逐一說明每個實驗的內容與用到的指令。

可以改進的地方：

- **延遲以空迴圈實作**。`lab11.c` 的 LED 動畫靠 `delay()` 忙碌等待控制速度，沒有使用計時器中斷，等待期間 CPU 無法做其他事。
- **陣列索引會超出範圍**。`lab11.c` 的 `speed` 陣列有三個元素，但 `int2()` 讓 `speedindex` 加到 3 之後才歸零，主迴圈會讀到 `speed[3]`。
- **中斷服務程式內有等待迴圈**。`lab11.c` 的 `int1()` 在中斷裡以 `while(1)` 持續掃描鍵盤，等待期間其他工作全部停住。
- **中斷與主迴圈共用的變數沒有保護**。`lab11.c` 的 `state`、`speedindex` 會被中斷服務程式修改，但沒有宣告為 `volatile`。
- **函式實作寫在標頭檔**。`kb44.h` 直接包含掃描函式的實作，而不是只放宣告。
- **數值直接寫在程式裡**。`TCON = 5`、`IE = 0X85` 這類暫存器設定沒有用具名常數或註解說明每個位元的意義。
- **Keil 提供的標頭檔一起進了版控**。`reg51.h` 與 `intrins.h` 是工具鏈附的檔案。
- **沒有專案檔與建置說明**。存放庫只有原始碼，沒有 Keil 專案檔，也沒有說明如何編譯與燒錄。
